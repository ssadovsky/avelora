# AGENTS.md — Avelora (для Codex и других агентов)

Игра: Three.js r128, **serverless `file://`**, без сборщиков и сервера. Полные правила проекта — в `CLAUDE.md` (английский/русский) и `GEMINI.md` (русский). Прочитай их до правок. Коротко главное:

- Не коммитить, не пушить, не откатывать, пока пользователь явно не просил. Файлы не удалять без разрешения.
- Игру открыть из среды нельзя: проверяй рендерами, `node --check`/`new Function`, загрузкой GLB; в игре проверяет пользователь («не проверено в игре» писать честно).
- После любой правки ассетов: `python3 temp_work/build_assets.py` и поднять `?v=` в `Avelora.html` и `CACHE_NAME` в `js/sw.js`.
- `temp_work/` в git не входит (инструменты и исходники на диске пользователя).

## Персонажи (герои): добавление, упрощение модели, хват посоха/лука, поза верхом

Всё описано в **`docs/CHARACTERS.md`** (пошаговый порядок, упрощение без порчи лица/деталей/цвета, сборка клипов, пропорции Meshy-рига, конфиг `characters.js`, хваты через кости пальцев или morph-target, верхом, проверка, подводные камни). Готовые инструменты: `temp_work/rig/tools/` (`README.md` там). Читай этот документ перед любой работой с героями, моделями героев, `characters.js`, `character.js`, `mount.js`.
